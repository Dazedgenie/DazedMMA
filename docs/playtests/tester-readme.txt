CHIN CHECK - PLAYTEST BUILD
===========================

Thanks for testing! This is a grey-box prototype: the fighters are capsules and
there is no art or sound yet. We're testing one thing: does coaching a fight
from the corner feel right?

HOW TO START
1. Unzip this folder anywhere (the Desktop is fine).
2. Double-click ChinCheck.exe.
   Windows may say "Windows protected your PC" because the game isn't signed.
   Click "More info", then "Run anyway".
3. Type your name in "Your name", pick "Playtest 1" in the Playtest list and
   press Start. Each fight shows a short tip first.

KEYS
  1-9, 0   calls (or click the buttons at the bottom)
  Q / E    read calls ("Catch the kick!" is Q)
  Space    slow motion on / off
  F        fast forward on / off
  T        throw in the towel (asks first)
  Esc      menu
  F3       debug numbers (you can ignore these)

AFTER EACH FIGHT
The game saves the fight by itself. Use "Next" to go on to the next playtest
fight. When you're done, press "Open saved fights" on the result screen and
send every file in that folder to the host. They are small text files with
the fight's numbers and its replay; nothing personal is in them except the
name you typed.

(The folder is %APPDATA%\Godot\app_userdata\Chin Check\fights if you need to
find it later.)

Then fill in the feedback form the host gives you. Honest answers help most:
"I didn't get it" is useful feedback.
